# MultipleLinearRegression-C
C言語を用いて、重回帰分析(複数の方程式からデータ予測を行う統計手法)の計算ロジックを1から実装したプロジェクトです。

## 概要と目的
大学のプログラムの一環として、データ分析の基礎となる数学的アルゴリズムを深く理解するため、C言語を用いて行列計算の基礎(偏差行列や行列の積など)からロジックを組み立てました。連立方程式の計算には外部アルゴリズムを取り入れつつ、分析の基盤となる処理を自作することで、重回帰分析の仕組みへの理解を深めました。

## 実装した機能
- **CSVデータの読み込み**
- **データの偏差行列・転置行列の作成(データの中心化処理)**
- **行列同士の積を行う自作関数の実装**
- **偏回帰係数および標準化係数の算出**
- **モデルの評価・統計的検定(F検定、決定係数、自由度調整済み決定係数の算出、各変数のt検定)**

## 構成ファイル（c_src）
本プロジェクトは、機能ごとにモジュール分割を行っています。

- `main.c` : ユーザーからのファイル名入力、各関数の呼び出し、メモリ管理を行う全体の制御ロジック。
- `data_loader.c` : CSVファイルからのデータサイズ（m, n）の先読み、およびデータの二次元配列への読み込み処理。
- `statistics.c` : 各説明変数および目的変数の平均値、不偏標準偏差を算出する処理。
- `regression.c` : 偏差行列・転置行列の作成、およびLU分解を用いた偏回帰係数・逆行列・切片の算出。
- `standardization.c` : 各変数の影響度を公平に比較するための標準化係数の算出。
- `matrix_ops.c` : 行列同士の積（かけ算）を計算する汎用的な行列演算ロジック。
- `main.h` : 各モジュール間で共有する関数のプロトタイプ宣言。
